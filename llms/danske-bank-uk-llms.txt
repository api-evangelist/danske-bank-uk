# Danske Bank (UK)

> Danske Bank (UK) is the trading name of Northern Bank Limited, the largest bank in Northern Ireland and one of the UK CMA9. As an FCA-authorised ASPSP under PSD2 it publishes the UK Open Banking (OBIE) API family — a public Open Data API plus FAPI-secured Read/Write APIs (AIS, PIS, CBPII, VRP, Events) — alongside a suite of premium corporate APIs on its developer portal.

## APIs

- [Open Data API](https://developers.danskebank.com/api_products/danske_bank_apis/od?view=reference): Public, unauthenticated OBIE Open Data v2.2 — ATMs, branches, personal/business current accounts, unsecured SME loans, commercial credit cards. Base: https://obp-data.danskebank.com/v2.2
- [Account and Transaction API (AIS)](https://developers.danskebank.com/): OBIE Read/Write AIS v4.0 — accounts, balances, transactions, beneficiaries, standing orders, direct debits, statements. Base: https://obp-api.danskebank.com/open-banking/v4.0/aisp
- [Payment Initiation API (PIS)](https://developers.danskebank.com/): OBIE Read/Write PIS v4.0 — domestic, scheduled, standing-order, file and international payments. Base: https://obp-api.danskebank.com/open-banking/v4.0/pisp
- [Confirmation of Funds API (CBPII)](https://developers.danskebank.com/): OBIE Read/Write CBPII v4.0 — confirm availability of funds. Base: https://obp-api.danskebank.com/open-banking/v4.0/cbpii
- [Variable Recurring Payments API (VRP)](https://developers.danskebank.com/): OBIE Read/Write VRP v4.0 — domestic VRP consents and recurring payments. Base: https://obp-api.danskebank.com/open-banking/v4.0/pisp
- [Events API](https://developers.danskebank.com/): OBIE Event Notification v4.0 — real-time resource-update notifications to TPPs. Base: https://obp-api.danskebank.com/open-banking/v4.0
- [Account Transaction & Balance API (premium)](https://developers.danskebank.com/): Corporate real-time transactions and balances. Base: https://api.danskebank.com/corporate/api/v1/account-transaction-service
- [Payment Collection API (premium)](https://developers.danskebank.com/): Corporate collection payment services. Base: https://api.danskebank.com/corporate/api/v1/collection-service
- [Premium Payment Initiation API](https://developers.danskebank.com/): Corporate payment orders. Base: https://api.danskebank.com/corporate/api/v1/corporate-paymentorders
- [FX Trade Report API (premium)](https://developers.danskebank.com/): Open and historical FX trade reports. Base: https://api.danskebank.com/corporate/api/v1/open-trades-service
- [FX Trade Execution API (premium)](https://developers.danskebank.com/): Execute FX trades against quotes. Base: https://api.danskebank.com/corporate/api/v1/trade-service
